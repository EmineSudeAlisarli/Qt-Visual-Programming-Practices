# Qt-Visual-Programming-Practices
Weekly practices, assignments, and UI projects for the Visual Programming lesson using C++ and Qt Framework.

# 3. Hafta: QPushButton ve QMessageBox Uygulamaları
Bu haftanın laboratuvar dersinde, QPushButton bileşeni üzerinden interaktif kullanıcı arayüzü öğeleri üzerinde çalışılmıştır. Uygulamalar kapsamında; butona tıklandığında konsola isim yazdırma , QDateTime sınıfı ile anlık sistem tarihini çekme ve rastgele sayı üretme gibi temel fonksiyonlar gerçekleştirilmiştir. Ayrıca QMessageBox sınıfı kullanılarak; Bilgi (Information), Uyarı (Warning), Soru (Question) ve Kritik (Critical) gibi farklı ikon ve buton yapılarına sahip mesaj kutuları üzerinden kullanıcı etkileşimi simüle edilmiştir. Son olarak, diyalog pencerelerinin programatik olarak kapatılması ve kullanıcıdan onay alma senaryoları "Kapat" butonları üzerinden deneyimlenmiştir.

# Week 9: Custom Analog Clock (Analog Saat Uygulaması)

Bu haftaki uygulamada, Qt Framework içerisinde yer alan `QPainter` sınıfı kullanılarak sıfırdan özel bir widget (analog saat) çizimi gerçekleştirilmiştir. Saat, sistem saatini anlık olarak okuyarak akrep, yelkovan ve saniye kollarını matematiksel hesaplamalarla doğru açılarda ekrana yansıtır.
